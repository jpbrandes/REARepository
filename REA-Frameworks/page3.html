Aplicação Prática: Construindo um CRUD Completo

Da teoria à prática: O Sistema To-Do List

Para consolidar todos os conceitos estudados sobre frameworks, arquitetura de software, runtimes e a separação entre Frontend e Backend, construímos uma aplicação funcional de Lista de Tarefas. O sistema implementa rigorosamente o modelo arquitetural CRUD (Create, Read, Update, Delete), permitindo criar, listar, atualizar e excluir registros de forma totalmente integrada.

A stack tecnológica Escolhida

  • Backend: Python com o framework FastAPI, escolhido pela alta performance e documentação automática de rotas.
  • Banco de Dados: SQLite, um banco relacional leve que gerencia os dados localmente em arquivo único.
  • Frontend: HTML, CSS e JavaScript puro (Vanilla JS), consumindo a API de forma assíncrona com fetch e gerenciando estados locais e modo escuro dinâmico.

Passo a passo do desenvolvimento

Passo 1: Instalação das dependências

No seu terminal, instale o FastAPI e o Uvicorn (servidor ASGI), essas duas dependências são usadas com a linguagem Python:

pip install fastapi uvicorn

Passo 2: O cérebro da aplicação (O Backend em Python)

O arquivo main.py gerencia o servidor, configura o CORS e estabelece todas as rotas de persistência:

from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel
import sqlite3

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

def conectar_db():
    conn = sqlite3.connect("banco.db")
    conn.row_factory = sqlite3.Row
    return conn

def inicializar_db():
    conn = conectar_db()
    conn.execute("""
        CREATE TABLE IF NOT EXISTS tarefas (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            titulo TEXT NOT NULL,
            concluida BOOLEAN NOT NULL DEFAULT 0
        )
    """)
    conn.commit()
    conn.close()

inicializar_db()

class Tarefa(BaseModel):
    titulo: str
    concluida: bool = False

@app.post("/tarefas")
def criar_tarefa(tarefa: Tarefa):
    conn = conectar_db()
    cursor = conn.cursor()
    cursor.execute("INSERT INTO tarefas (titulo, concluida) VALUES (?, ?)", (tarefa.titulo, tarefa.concluida))
    conn.commit()
    novo_id = cursor.lastrowid
    conn.close()
    return {"id": novo_id, "titulo": tarefa.titulo, "concluida": tarefa.concluida}

@app.get("/tarefas")
def listar_tarefas():
    conn = conectar_db()
    cursor = conn.cursor()
    cursor.execute("SELECT * FROM tarefas")
    tarefas = [dict(row) for row in cursor.fetchall()]
    conn.close()
    return tarefas

@app.put("/tarefas/{tarefa_id}")
def atualizar_tarefa(tarefa_id: int, tarefa: Tarefa):
    conn = conectar_db()
    cursor = conn.cursor()
    cursor.execute("UPDATE tarefas SET titulo = ?, concluida = ? WHERE id = ?", (tarefa.titulo, tarefa.concluida, tarefa_id))
    conn.commit()
    conn.close()
    return {"mensagem": "Tarefa atualizada com sucesso!"}

@app.delete("/tarefas/{tarefa_id}")
def deletar_tarefa(tarefa_id: int):
    conn = conectar_db()
    cursor = conn.cursor()
    cursor.execute("DELETE FROM tarefas WHERE id = ?", (tarefa_id,))
    conn.commit()
    conn.close()
    return {"mensagem": "Tarefa deletada com sucesso!"}

@app.delete("/tarefas")
def deletar_todas_tarefas():
    conn = conectar_db()
    cursor = conn.cursor()
    cursor.execute("DELETE FROM tarefas")
    conn.commit()
    conn.close()
    return {"mensagem": "Todas as tarefas foram deletadas!"}

Passo 3: Como rodar o servidor backend

Com o arquivo salvo, ative o servidor local via Uvicorn:

uvicorn main:app --reload

        async function carregarTarefas() {
            const resposta = await fetch('http://127.0.0.1:8000/tarefas');
            const tarefas = await resposta.json();
            
            const lista = document.getElementById('listaTarefas');
            lista.innerHTML = '';
            
            if (tarefas.length === 0) {
                lista.innerHTML = '<p style="text-align: center; color: var(--border-color);">Nenhuma tarefa cadastrada ainda.</p>';
                return;
            }

            tarefas.forEach(t => {
                lista.innerHTML += `
                    <li>
                        <span>${t.titulo}</span>
                        <div class="acoes">
                            <button class="btn-concluir" onclick="deletarTarefa(${t.id})">Concluir</button>
                            <button class="btn-editar" onclick="editarTarefa(${t.id}, '${t.titulo}', ${t.concluida})">Editar</button>
                            <button class="btn-excluir" onclick="deletarTarefa(${t.id})">Excluir</button>
                        </div>
                    </li>
                `;
            });
        }

        async function adicionarTarefa() {
            const input = document.getElementById('novaTarefa');
            if (!input.value.trim()) return;

            await fetch('http://127.0.0.1:8000/tarefas', {
                method: 'POST',
                headers: { 'Content-Type': 'application/json' },
                body: JSON.stringify({ titulo: input.value, concluida: false })
            });

            input.value = '';
            carregarTarefas();
        }

        async function editarTarefa(id, tituloAntigo, statusAtual) {
            const novoTitulo = prompt("Edite o nome da tarefa:", tituloAntigo);
            if (novoTitulo === null || !novoTitulo.trim()) return;

            await fetch(`http://127.0.0.1:8000/tarefas/${id}`, {
                method: 'PUT',
                headers: { 'Content-Type': 'application/json' },
                body: JSON.stringify({ titulo: novoTitulo, concluida: statusAtual })
            });

            carregarTarefas();
        }

        async function deletarTarefa(id) {
            await fetch(`http://127.0.0.1:8000/tarefas/${id}`, {
                method: 'DELETE'
            });
            carregarTarefas();
        }

        async function deletarTodasTarefas() {
            if (confirm("Tem certeza absoluta que deseja apagar TODAS as tarefas?")) {
                await fetch('http://127.0.0.1:8000/tarefas', {
                    method: 'DELETE'
                });
                carregarTarefas();
            }
        }

        function alternarTema() {
            document.body.classList.toggle('dark-mode');
            const botao = document.getElementById('botao-tema');
            
            if (document.body.classList.contains('dark-mode')) {
                localStorage.setItem('tema', 'escuro');
                botao.innerHTML = 'Modo Claro';
            } else {
                localStorage.setItem('tema', 'claro');
                botao.innerHTML = 'Modo Escuro';
            }
        }

        window.addEventListener('DOMContentLoaded', () => {
            const temaSalvo = localStorage.getItem('tema');
            const botao = document.getElementById('botao-tema');
            
            if (temaSalvo === 'escuro') {
                document.body.classList.add('dark-mode');
                if (botao) botao.innerHTML = 'Modo Claro';
            }
            carregarTarefas();
        });
    </script>
