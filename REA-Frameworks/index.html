1. Definição conceitual

O desenvolvimento de software possui regras rígidas de produção. Ao longo do desenvolvimento da web e de soluções computacionais, surgiram os chamados frameworks de programação, que são uma coletânea de ferramentas produzidas para amplificar a velocidade de desenvolvimento. Em outras palavras, é possível entender um frameworks como uma planta de uma casa, você já possui uma estrutura pronta, basta seguir os passos para montá-la.

Antes de citar exemplos de frameworks e seus usos, é necessário entender conceitos como frontend e backend. O backend de uma aplicação é seu mecanismo interno, toda a relação com os dados do usuário é ocorrida no backend, isso desde como o dado será manipulado e até onde ele será armazenado. O denominado frontend por sua vez, carrega a missão de ser intuitivo para o usuário, isso significa decisões sobre estrutura de menus, cor de botões, menus interativos e uma interface intuitiva. Ambas as etapas do processo são críticas para uma boa aplicação.
