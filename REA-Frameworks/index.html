Frameworks de programação

Definições conceituais

O desenvolvimento de software possui regras rígidas de produção. Ao longo do desenvolvimento da web e de soluções computacionais, surgiram os chamados frameworks de programação, que são uma coletânea de ferramentas produzidas para amplificar a velocidade de desenvolvimento. Em outras palavras, é possível entender um framework como a planta de uma casa: você já possui uma estrutura pronta, basta seguir os passos para montá-la.

Antes de citar exemplos de frameworks e seus usos, é necessário entender conceitos como frontend e backend. O backend de uma aplicação é seu mecanismo interno; toda a relação com os dados do usuário ocorre nele, desde como o dado será manipulado até onde ele será armazenado. O denominado frontend, por sua vez, carrega a missão de ser intuitivo para o usuário, o que significa decisões sobre estrutura de menus, cor de botões, elementos interativos e uma interface acessível. Ambas as etapas do processo são críticas para uma boa aplicação.

É bem comum confundir frameworks, bibliotecas e runtimes (ambientes de execução). As diferenças entre eles são evidentes e fazem bastante diferença na prática: um framework é uma estrutura completa que dita a arquitetura do projeto; uma biblioteca é uma junção de ferramentas pontuais onde você tem total poder de escolha para usar apenas o que precisar; por fim, um runtime é o ambiente de execução onde o código roda (como no Java, que utiliza um ambiente próprio para rodar em qualquer lugar). Através deste material, focarei exclusivamente em frameworks.

Exemplos de frameworks

Frameworks Backend

  • Express.js: É um framework minimalista e muito rápido para Node.js (JavaScript), ideal para criar APIs e aplicativos web leves sem complicações.
  • NestJS: Um framework moderno para TypeScript que ajuda a criar aplicações Node.js organizadas e fáceis de manter em grandes empresas.
  • Django: Uma opção em Python que vem "com tudo incluso" (como painel de controle e segurança), perfeito para criar sites e sistemas completos rapidamente.
  • FastAPI: Framework em Python focado em altíssima velocidade e performance, muito usado para conectar inteligências artificiais e sistemas de dados.
  • Spring Boot: Framework em Java extremamente robusto, seguro e estável, sendo a escolha favorita de bancos e grandes corporações no mercado.
  • ASP.NET Core: Desenvolvido pela Microsoft (C#), é uma ferramenta multiplataforma de altíssimo desempenho para sistemas empresariais.
  • Laravel: Um framework em PHP muito popular que facilita a criação de sistemas web e lojas virtuais com um código limpo e elegante.
  • Ruby on Rails: Focado na rapidez de desenvolvimento, ajuda startups a tirarem suas ideias do papel criando sistemas completos em pouquíssimo tempo.

Frameworks Frontend

  • Vue.js: Um framework muito leve e amigável para iniciantes, ideal para criar telas interativas com uma curva de aprendizado suave.
  • Angular: Mantido pelo Google, é uma plataforma completa e rígida que traz todas as ferramentas necessárias para construir sistemas web gigantescos.
  • Svelte: Uma abordagem diferente que faz todo o trabalho duro durante a compilação, entregando sites extremamente rápidos e sem códigos pesados.
  • Next.js: Um framework baseado em React que melhora o carregamento das páginas e o SEO (busca no Google), preparando o site direto no servidor antes de enviar ao usuário.
  • Nuxt.js: Funciona de forma parecida com o Next.js, mas é feito sob medida para quem usa Vue.js, adicionando superpoderes de carregamento e organização aos projetos.
  • SolidJS: Um framework focado em performance extrema que usa uma lógica parecida com o React, mas atualiza a tela de forma muito mais rápida e cirúrgica.

Vantagens de uso

A primeira vantagem a ser analisada é a reutilização do código gerado, ao invés de precisar reescrever tudo do zero e perder um tempo valioso refazendo código, os frameworks deixam isso mais rápido. Padronização também é uma boa característica, ao invés de todo programador escrever seu próprio código, essa padronização diminui a chance de confusões entre grupos de desenvolvedores e aumenta a legibilidade e compreensão do código escrito.

Uma das vantagens mais legais do uso de frameworks também é sobre a manutenibilidade, o código escrito não é algo estático, mas sim volátil, dependente de atualizações. Uma aplicação, deve ser atualizada conforme as regras de sistemas mudam e acompanhar as tecnologias do mercado.

Por outro lado, o uso de frameworks também traz desafios. O principal deles é a curva de aprendizado, já que o desenvolvedor precisa dominar as regras específicas daquela ferramenta antes de ser produtivo. Além disso, existe o risco de superengenharia, que é usar uma estrutura gigante e pesada para resolver um problema que seria simples de solucionar com código puro.
